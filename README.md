## Чем могу помочь

- **Python-скрипты и автоматизация** — убрать повторяющиеся ручные операции.
- **Excel, CSV, JSON и TXT** — обработать, преобразовать или объединить файлы.
- **Telegram-боты** — команды, сценарии и подключение внешних API.
- **API и веб-сервисы** — небольшие приложения на FastAPI или Flask.
- **SQL и базы данных** — простые запросы, схемы и интеграция с приложением.
- **Отладка Python-кода** — найти причину ошибки и подготовить исправление.

Работаю с небольшими задачами с понятным результатом. Перед началом уточняю входные данные, ожидаемый результат и критерии готовности.
